# Ask Fubo Web prototype: source

- `../ask-fubo-web.html` is the finished single-file prototype. Open it in a browser.
- `src.html` is the editable source.
- `assets/` has everything the build needs (fonts, Fubo Web components, images, logo, background).
- `python3 build.py` rebuilds `../ask-fubo-web.html` from `src.html` and `assets/`.
